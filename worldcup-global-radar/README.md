# World Cup 2026 Global Radar

Static visual archive for the Lark global World Cup radar.

- `index.html`: global radar archive portal.
- `reports/YYYY-MM-DD.html`: archived visual report.
- `reports/YYYY-MM-DD.md`: archived text report.
- `scripts/build_index.py`: rebuilds the archive portal.
- `scripts/send_lark.py`: sends a structured Lark card pointing to the global visual report.
