# 关系喜剧 / 夫妻关系类模式库

适用于夫妻、情侣、亲密伴侣之间的短视频喜剧。核心不是“吵架”本身，而是用亲密关系里的权力、欲望、面子、占有欲、日常琐事制造冲突，再用反转/打脸/抓包完成笑点。

## 总识别框架

分析夫妻关系类视频时，必须追问：

1. 夫妻双方权力关系是什么？谁强谁弱？
2. 谁先占上风？谁后来被打脸？
3. 冲突来自什么：日常琐事、性需求、好色、面子、钱、家务、承诺？
4. 情绪转折点在哪里？
5. 结尾谁赢、谁输、谁认怂？
6. 哪些元素可以替换复用？

## 子类型 1：夫妻吵架（日常琐事 + 面子崩塌）

### 定义

通过幽默对话和情节反转，展现夫妻因日常琐事、情感误解、性别角色冲突而引发的争执与和解。

### 核心机制

一方先嘴硬/吹牛/讲道理，最后被现实打脸。

### 常见故事链

1. 日常问题出现：院子没人打扫、家务没人做、钱不够、孩子没人管。
2. 一方自信承诺：我兄弟多、朋友铁、我能搞定。
3. 连续失败验证：三段式求助亲戚/兄弟/朋友，均被拒绝。
4. 另一方总结打脸：平时吃喝玩乐都在，关键时刻没人帮。
5. 回到现实解决方案：掏钱找人、自己干、被伴侣教育。

### 必须识别的关键点

- 是否有“吹牛/自信承诺”。
- 是否有连续求助失败，尤其三段式递进。
- 是否有伴侣的总结性打脸。
- 是否从“面子强势”转成“现实无奈”。

### 验证问题

- 主角承诺了什么？
- 求助对象是谁？每次拒绝理由是什么？
- 是否形成三段递进？
- 伴侣最后是否给出价值判断/现实方案？

### 可替换部分

- 求助事项：修整院子、搬家、辅导孩子、修电脑、借钱、装修、搬家具。
- 求助对象：亲哥、朋友、老同学、前同事、邻居、亲戚。
- 拒绝借口：生病、没空、买新车、老婆不同意、正在外地。
- 结尾打脸：花钱解决、自己干、被老婆教育。

### 案例规则

案例：丈夫说自己兄弟朋友亲戚都会来帮忙打扫院子，连续打三个电话都被拒绝，妻子指出平时朋友关键时刻靠不住，最后还是要花钱找人。

正确理解：这是“人脉吹牛 → 三段失败 → 妻子现实打脸”的夫妻吵架段子。

容易误判：只总结成“夫妻讨论打扫院子”，会漏掉核心爆点“人脉/面子被现实打脸”。

## 子类型 2：夫妻好色（欲望暴露 + 当场抓包）

### 定义

通过展现丈夫/妻子对美女/帅哥的好奇、偷看或追求，引发伴侣愤怒和冲突，反映占有欲、嫉妒心理和性别角色对立。

### 核心机制

一方被第三方吸引，欲望外露，另一方抓包并惩罚。

### 常见故事链

1. 稳定关系场景：夫妻坐车、吃饭、逛街、电梯里。
2. 第三方诱因出现：美女/帅哥靠近。
3. 好色方失控：偷看、搭讪、吹口哨、降车窗、偷拍。
4. 伴侣察觉：眼神变化、沉默、质问。
5. 翻车惩罚：暴揍、抢手机、怒骂、尴尬认怂。

### 必须识别的关键点

- 是否出现第三方吸引对象。
- 是否有偷看/搭讪/失控动作。
- 伴侣是否从平静转为愤怒。
- 是否有“抓包爽点”：观众提前预判翻车。
- 是否有语言歧义，如“继续”等双关被伴侣放大矛盾。

### 验证问题

- 好色方具体做了什么？看、说、靠近、开窗、偷拍？
- 伴侣何时发现？表情/动作如何变化？
- 惩罚或翻车是否可见？
- 第三方是否只是路过，还是参与互动？

### 可替换部分

- 偷看方式：后视镜、车窗反光、手机偷拍、墨镜偷瞄。
- 搭讪行为：开窗、问路、夸赞、吹口哨、表情夸张。
- 冲突升级：抢手机、暴揍丈夫、公开羞辱、冷暴力。
- 场景空间：车内、餐厅、电梯、公园、商场。

### 案例规则

案例：夫妻坐车里，美女把车窗当镜子照镜子，丈夫一直看并把车窗放下来搭话，妻子生气暴揍丈夫。

正确理解：这是“美女诱因 → 丈夫欲望外露 → 妻子抓包 → 暴力惩罚”的夫妻好色段子。

容易误判：只写“车内发生争吵”，会漏掉第三方诱因和抓包爽点。

## 子类型 3：妻管严（强弱地位反转 + 卑微求和）

### 定义

通过展现妻子在家庭决策和日常生活中占主导地位，强调丈夫在强势管理下的无奈与幽默冲突，形成性别角色反转。

### 适合人设

- 丈夫：懦弱、嘴硬、卑微、爱放狠话但行动软。
- 妻子：强势、冷静、不屑、掌控局面。

### 核心机制

丈夫开头装强势，结尾暴露真实家庭地位，变成卑微讨好。

### 常见故事链

1. 丈夫放狠话：我要离家出走、我再也不回来了、我不干了。
2. 妻子冷处理/不屑：不阻拦，甚至默认他走。
3. 丈夫开始拖延：洗碗、做饭、叠衣服、找借口。
4. 时间不断变化：字幕显示从早到晚，一直没走。
5. 丈夫求和：送礼物、讨好、认错，妻子继续掌控局面。

### 必须识别的关键点

- 丈夫前后态度是否反差极大。
- 妻子是否强势/冷静/不屑。
- 是否有时间流逝字幕强化“赖着不走”。
- 是否最后丈夫主动求和。

### 验证问题

- 丈夫开头说了什么狠话？
- 妻子是否阻拦，还是冷处理？
- 丈夫拖延的动作有哪些？
- 时间字幕是否推动笑点？
- 结尾丈夫是否送礼/认错/讨好？

### 可替换部分

- 离家出走原因：吵架、没零花钱、被骂、吃醋、家务分配。
- 赖着不走行为：打扫卫生、做饭、洗碗、拖地、修家具、带孩子。
- 最终礼物：手机、衣服、花、食物、红包。
- 结尾：妻子收礼但继续冷脸；丈夫彻底认怂；妻子一句话重新掌控。

### 案例规则

案例：丈夫睡前说醒来就离家出走，第二天醒来却洗碗、做家务、叠衣服，一直赖着不走，最后给妻子送礼物卑微求和。

正确理解：这是“放狠话 → 拖延不走 → 卑微求和”的妻管严段子。

容易误判：只写“丈夫做家务”，会漏掉开头强势与结尾卑微之间的权力反转。

## 子类型 4：亲密需求反转（性/亲密期待错位）

### 定义

夫妻/情侣之间围绕亲密行为、调情、拒绝产生冲突，常通过性别预期反转和露骨语言制造笑点。

### 核心机制

常规期待被反转：通常观众预期丈夫主动，但视频让妻子主动、丈夫拒绝，从而制造荒诞反差。

### 常见故事链

1. 一方主动调情或提出亲密需求。
2. 另一方用低价值日常理由拒绝：看电视、打游戏、看球、刷视频。
3. 主动方从调情转为愤怒/威胁。
4. 拒绝方继续毒舌或回怼。
5. 情绪迅速升级成互放狠话。

### 必须识别的关键点

- 是否存在亲密暗示/露骨对白/肢体互动。
- 是否发生性别预期反转。
- 拒绝理由是否低价值且日常。
- 情绪是否从调情快速转为争吵。

### 验证问题

- 谁主动？谁拒绝？
- 拒绝理由是什么？
- 是否有威胁第三方，如“去找邻居”？
- 回怼是否构成最后反转？

### 可替换部分

- 丈夫借口：看电视、打游戏、看足球赛、刷视频。
- 妻子道具/表现：性感打扮、新裙子、内裤、肢体靠近。
- 结局：妻子威胁找邻居；切断电视电源；丈夫把妻子关门外；双方互骂。

### 案例规则

案例：妻子试图用露骨言语和肢体互动诱惑丈夫，丈夫只想看电视并毒舌说看腻老婆的脸，引发互放狠话。

正确理解：这是“亲密需求性别反转 → 低价值拒绝 → 毒舌升级”的夫妻亲密需求反转段子。

容易误判：只写“夫妻吵架”，会漏掉黄段子、性别预期反转和低价值拒绝的荒诞感。

## HTML 输出建议

对关系喜剧类视频：

- `视频整体内容总结` 要明确子类型和故事链，例如：这条是“妻管严”段子，笑点来自丈夫前后态度反差。
- `核心爆点` 优先写：权力反转、抓包爽点、三段式打脸、性别预期反转、毒舌升级。
- `可替换部分` 优先写：场景、人物关系、冲突事项、借口/诱因、结尾反转。
- `脚本表` 要把关键对白/字幕写清楚，因为关系喜剧通常高度依赖对白。
